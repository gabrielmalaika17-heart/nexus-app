# Installer NEXUS sur ton iPhone

Tu n'as pas besoin de Mac pour tester cette version. Il faut seulement publier le dossier sur une URL HTTPS, puis l'ouvrir avec Safari sur ton iPhone.

## Option recommandee : GitHub Pages

1. Cree un compte GitHub si tu n'en as pas.
2. Cree un nouveau depot appele `nexus-app`.
3. Ajoute tous les fichiers de ce dossier dans le depot.
4. Va dans Settings, puis Pages.
5. Choisis la branche principale et le dossier racine.
6. GitHub te donne une URL du type `https://tonnom.github.io/nexus-app/`.
7. Ouvre cette URL dans Safari sur ton iPhone.
8. Appuie sur le bouton Partager.
9. Choisis Ajouter a l'ecran d'accueil.

## Ce que tu obtiens

- Une icone NEXUS sur l'iPhone.
- Une ouverture plein ecran comme une app.
- Les donnees sauvegardees localement.
- Un mode hors ligne apres la premiere ouverture.

## Limite

Cette version ne peut pas bloquer reellement Instagram, TikTok ou YouTube. Elle prepare le parcours volontaire et guide l'utilisateur vers Temps d'ecran. Le blocage natif demandera plus tard une vraie app iOS avec autorisations Apple.
